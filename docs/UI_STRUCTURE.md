
# Event-Board – UI-Struktur und Navigation

## 1. Ziel

Die Anwendung wird als responsive Single-Page-
Application (SPA) mit React entwickelt.

Die Benutzeroberfläche unterstützt Deutsch
und Englisch.

## 2. Hauptansichten

### 01 – Startseite (Home)
- Einführung in Event-Board
- Navigation
- Registrierung und Anmeldung

### 02 – Registrierung und Login
- Registrierungsformular
- Anmeldeformular
- Validierung und Fehlermeldungen

### 03 – Event-Übersicht
- Alle veröffentlichten Veranstaltungen
- Event-Karten mit Vorschaubild
- Titel, Kurzbeschreibung und Veranstalter

### 04 – Event-Details
- Vollständige Veranstaltungsinformationen
- Großes Event-Bild
- Anmeldung und Abmeldung
- Likes, Dislikes und Kommentare

### 05 – Event erstellen / bearbeiten
- Formular für Veranstaltungsdaten
- Bild hochladen
- Entwurf speichern
- Event veröffentlichen

### 06 – Meine Veranstaltungen
- Eigene Entwürfe
- Eigene veröffentlichte Events
- Events bearbeiten und verwalten

### 07 – Meine Anmeldungen
- Veranstaltungen mit eigener Anmeldung
- Teilnahme stornieren

## 3. Optionale Ansicht

### 08 – Benutzerprofil
- Eigene Profildaten anzeigen und bearbeiten
- Andere Benutzerprofile ansehen

## 4. Allgemeine UI-Elemente

- Header und Navigation
- Sprachumschaltung DE / EN
- Responsive Design
- Fehlermeldungen und Erfolgsmeldungen
- Footer

## 5. Designplanung

- React mit Vite
- Tailwind CSS
- Forest-/Amber-Farbkonzept
- Desktop- und Mobile-Ansichten
